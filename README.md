Чек-ліст завдань
Обов'язкові завдання:

 Завдання 1: Відрендерити продукти в таблиці з id, назвою, категорією та власником (користувачем)

 Категорія повинна показувати іконку перед назвою
 Імена власників мають бути забарвлені has-text-link для чоловіків і has-text-danger для жінок


 Завдання 2: Реалізувати можливість фільтрації продуктів за власником

 Якщо користувач обраний, він має бути виділений класом is-active
 Показувати тільки продукти обраного користувача
 Вибрати All щоб побачити всі продукти


 Завдання 3: Використовувати input для фільтрації продуктів за назвою

 Показувати тільки продукти, які містять значення з input у своїй назві (ігноруючи регістр)
 Кнопка x має з'являтися тільки коли значення не порожнє
 Очищати значення після кліку на кнопку x


 Завдання 4: Показати повідомлення No results, якщо немає продуктів, що відповідають поточним критеріям

 Кнопка Reset All Filters має очищати всі фільтри



Додаткові завдання (*):

 Завдання 5 (*): Дозволити вибирати кілька категорій

 Додати клас is-info до обраних категорій
 Показувати тільки продукти обраних категорій
 Кнопка All має очищати вибір
 Прибрати клас is-outlined з кнопки All, якщо категорії не обрані


 Завдання 6 (*): Додати можливість сортування продуктів по всіх колонках

 Колонка має мати заголовок з іконкою fa-sort за замовчуванням
 Перший клік сортує продукти за даною колонкою за зростанням і використовує іконку fa-sort-up
 Другий клік сортує продукти за спаданням і використовує іконку fa-sort-down
 Третій клік вимикає сортування
 Продукти сортуються по 1 колонці за раз (скидати заголовок колонки при кліку на іншу)
